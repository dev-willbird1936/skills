# Agent Advisor Skills

Three reusable agent skills for supervising work and consulting Codex or Claude advisors:

- [`babysit`](babysit/SKILL.md) — supervise a separate agent task through verified completion.
- [`codex-advisor`](codex-advisor/SKILL.md) — consult GPT-5.6 Sol through Codex CLI.
- [`claude-advisor`](claude-advisor/SKILL.md) — consult Fable 5 through Claude Code.
